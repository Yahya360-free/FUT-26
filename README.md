# ⚽ Football Technical 26 (FUT 26)

**Everest Company Game Development** tarafından geliştirilen C++ tabanlı, metin odaklı detaylı futbol menajerlik simülasyonu.

## 🚀 Özellikler
- 🌍 **Küresel Lig & Turnuva Veritabanı:** FIFA, UEFA, CONMEBOL, CAF, AFC, OFC turnuvaları ve milli takımlar.
- ⚽ **Canlı Maç Motoru:** Daktilo animasyonlu canlı spiker anlatımı, şut, gol, kart ve sakatlık dinamikleri.
- 💼 **Transfer & Gözlemcilik:** Oyuncu pazarlığı, altyapıdan wonderkid üretimi.
- 🎙️ **Menajerlik Etkileşimleri:** Basın toplantıları, soyunma odası morali ve kulüp finansı yönetimi.
- 💾 **Kayıt Sistemi:** `.txt` tabanlı kariyer kaydetme ve geri yükleme.

## 🛠️ Nasıl Çalıştırılır?
Herhangi bir C++ derleyicisi (GCC, Clang, MSVC) ile derleyebilirsiniz:

```bash
g++ FUT26_Ultimate_Master.cpp -o FUT26
./FUT26
